# Winter

> Live network and system telemetry in the Windows taskbar.

**Winter** is a lightweight **Win**dows moni**tor**.

It keeps stats visible on the taskbar. Currently includes upload/download rates, CPU and GPU usage and power, and RAM and VRAM usage.

It also comes with a Control Center for people who really want to have one.

## Install

Download `Winter-<version>-windows-x64.zip` from [Releases](https://github.com/Elypha/Winter/releases), extract it to a writable folder, and run `Winter.exe`. Settings and logs stay in that folder.

## Use

- Drag the taskbar readout to reposition it.
- Right-click it to open the menu.

Unavailable hardware sensors are shown as `N/A`.
